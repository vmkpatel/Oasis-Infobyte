# 🐍 Oasis Infobyte Python Development Projects for Internship

## 📌 Overview

This repository contains a collection of Python-based applications developed as part of the Oasis Infobyte Internship Program. The projects demonstrate practical applications of Python programming, including automation, utility tools, API integration, and voice-based interaction systems.

These projects helped strengthen skills in Python development, user interaction, API consumption, and problem-solving.

---

## 🚀 Projects Included

### 1. BMI Calculator

A Python application that calculates the Body Mass Index (BMI) based on a user's height and weight.

#### Features

* Calculates BMI instantly
* Categorizes BMI levels
* Simple user-friendly interface
* Health status evaluation

#### Technologies

* Python
* Mathematical Computation

---

### 2. Random Password Generator

A utility application that generates secure and random passwords based on user-defined criteria.

#### Features

* Strong password generation
* Customizable password length
* Includes uppercase, lowercase, digits, and symbols
* Improved password security

#### Technologies

* Python
* Random Module
* String Module

---

### 3. Weather Application

A weather forecasting application that retrieves real-time weather information using external APIs.

#### Features

* Current weather information
* Temperature display
* Humidity and atmospheric conditions
* City-based weather search

#### Technologies

* Python
* Weather API
* Requests Library
* JSON Processing

---

### 4. Voice Assistant

A voice-controlled virtual assistant capable of performing basic tasks using speech recognition.

#### Features

* Voice command recognition
* Text-to-speech functionality
* Automated responses
* Hands-free interaction

#### Technologies

* Python
* Speech Recognition

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/veeramalla-manikanta/Oasis-Infobyte.git
cd Oasis-Infobyte
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

If no requirements file exists, install required libraries manually:

```bash
pip install requests
pip install pyttsx3
pip install SpeechRecognition
```
